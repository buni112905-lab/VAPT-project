Executive Summary

This report presents the results of a structured Vulnerability Assessment and Penetration Testing (VAPT) engagement conducted against a Metasploitable 2 virtual machine at IP address 192.161.16.133. The assessment was performed in a controlled lab environment using industry-standard tools and methodologies spanning five distinct phases: Reconnaissance, Scanning & Enumeration, Vulnerability Assessment, Exploitation, and Reporting.

The target system is running Ubuntu Linux 8.04 — an operating system that reached Security End-of-Life on May 9, 2013, leaving it more than 12 years without security patches. The assessment uncovered 22 vulnerabilities across the host, including multiple Critical-severity issues that allowed complete root-level compromise of the system through several independent attack vectors.

Key findings include a live UnrealIRCd backdoor, an unauthenticated bind shell, a VNC server accessible with the password 'password', world-readable NFS shares, and exploitable legacy services (rlogin, rsh, distcc). All exploitations were conducted ethically, within scope, and solely for educational and assessment purposes.

Overall Risk Rating: CRITICAL — Immediate remediation is required. The system should be considered fully compromised and must not be exposed to any untrusted network.

Phase 1 — Reconnaissance

Passive and active information gathering to identify the target host and its basic characteristics.

Phase 1 / 5
1.1 Objective

Reconnaissance is the first and most critical phase. The goal is to gather as much information as possible about the target before any active probing begins. In this lab environment, the target is already known, but host discovery is performed to confirm the target is live and gather initial OS/network information.

1.2 Host Discovery

A network ping sweep was performed against the local subnet to identify the live Metasploitable 2 machine:

A full Nessus scan was performed against the target. The scanner identified 22 vulnerabilities across the host, ranging from Critical remote code execution issues to informational findings. The scan policy used was "Full Scan" with credential-less black-box testing.

4.1 Exploit #1 — UnrealIRCd Backdoor (Port 6697)

The UnrealIRCd 3.2.8.1 backdoor was exploited using the Metasploit module exploit/unix/irc/unreal_ircd_3281_backdoor. The backdoor triggers when any data prefixed with the sequence AB is sent to the IRC port.
